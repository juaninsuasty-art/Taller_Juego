# Arkanoid - Metodología de Desarrollo de Software

## Descripción

Este proyecto es un juego tipo Arkanoid desarrollado en Python usando pygame-ce.

El jugador controla una plataforma en la parte inferior de la pantalla. El objetivo es evitar que la pelota caiga y destruir los ladrillos ubicados en la parte superior.

## Tecnologías utilizadas

- Python
- pygame-ce
- Visual Studio Code
- Git
- GitHub
